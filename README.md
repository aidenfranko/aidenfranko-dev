# aidenfranko.dev
 
Personal portfolio of Aiden Franko, built with plain HTML, CSS, and JavaScript and deployed on Netlify.
 
Live: https://aidenfranko.dev
 
## Run locally
Open `index.html` in a browser, or serve the folder:
 
    npx serve .
 
## Structure
- `index.html` page markup
- `css/styles.css` styles
- `js/main.js` scripts
